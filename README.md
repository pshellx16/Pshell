## About Pshell
**Pshell** is an independent, open-source security and systems lab focused on building lightweight CLI utilities, automation scripts, and technical documentation from first principles. Everything is built and documented in the open—without bloat.

## Core Focus Areas
- **Security & Networking:** TCP/IP analysis, DNS/HTTP diagnostics, and foundational security labs.
- **Automation & Tooling:** Minimalist Python and Bash scripts for system tasks and workflow automation.
- **Linux Systems:** CLI environments, shell scripting, and system administration.

## Repositories & Labs
- **[Cybersecurity Lab](https://github.com/pshellx16/cybersecurity)** — Notes, scripts, and hands-on security experiments.
- **Python Practice Scripts** — Core logic, file handling, and foundational automation tools.
- **CLI Task Automator** *(In Development)* — Lightweight Linux + Python command-line utility.
- **FocusTube** *(In Planning)* — Distraction-free utility concept.

## Principles
- **Minimal & Lightweight:** Zero unnecessary dependencies or bloat.
- **Built in the Open:** Transparent code, reproducible setups, and documented experiments.
